# Guitar Trainer

ギターの基礎練習を、TAB・メトロノーム・入力音声の採点・成長記録まで1つにまとめたデスクトップアプリです。

## 現在できること

- 入力/出力オーディオデバイスの選択
- BPM・拍子を指定したメトロノーム
- 6弦TABグリッドで練習譜面を作成、保存、編集
- TABをクリック音に同期してギター風の合成音でプレビュー
- 4拍カウントイン後、演奏の単音ピッチとタイミングをリアルタイム解析
- 音程・リズム・総合スコアをSQLiteへ保存
- 練習履歴とスコア推移をグラフ表示

このMVPはクロマチックスケールやペンタトニックスケールなど、**単音フレーズ**を対象にしています。コードの音程分離や細かなミュート品質の判定は今後の拡張対象です。

## 開発環境

このプロジェクトでは、テスト・起動・ビルドのすべてにWindows側のuvを使用します。WSL側のPythonやuvで `.venv` を作成しないでください。

Windows uvの既定パスは `/mnt/c/Users/katao/.local/bin/uv.exe` です。異なる場所へインストールしている場合は、`make WUV=/path/to/uv.exe test` のように上書きできます。

初回または依存関係を変更した場合：

```bash
make sync
```

アプリの起動：

```bash
make run
```

初回起動時にサンプル「クロマチック基礎」が作成されます。データベースは `~/.gt_trainer/trainer.db` に保存されます。

## 使い方

1. 上部の `IN` にギター入力、`OUT` にヘッドホン等を指定します。
2. `TABエディター` でセルへフレット番号（0〜24）を入力し、保存します。
3. `今日の練習` でBPMを決めます。`お手本を再生` で譜面を確認できます。
4. `採点を開始` を押すと4拍のカウントインが始まります。採点中は音の回り込みを防ぐため、お手本音を鳴らさずクリックだけを出します。
5. 結果は `成長レポート` に蓄積されます。

ギターはオーディオインターフェースへ直接接続し、スピーカーではなくヘッドホンでクリックを聴くことを推奨します。入力へクリックが回り込むと採点精度が落ちます。

## テスト

```bash
make test
```

構文チェックを含めて一括検証する場合：

```bash
make check
```

## Windowsアプリのビルド

cx_Freezeで配布用ディレクトリを生成します。

```bash
make build
```

実行ファイルは `dist/gt_trainer/GuitarTrainer.exe` に生成されます。生成物を削除する場合は次を実行します。

```bash
make clean
```

音声評価の閾値は [music.py](src/gt_trainer/music.py)、ピッチ検出と音声合成は [audio.py](src/gt_trainer/audio.py) に分離しています。将来、録音済みデータを使った評価器やミュート判定器へ交換できます。
